# Travel site photography

Destination images depict Lisbon, Kyoto, and Vancouver. Property photographs are illustrative stock photography for the fictional stays, not photographs of real properties with those names. No paid image service or AI generation was used.

All photographs are packaged in `frontend/public/photos/`, served by the app, and require no external image requests at runtime. WebP images use browser lazy loading except for the hero. The frontend container includes the public directory in both deployment profiles.
