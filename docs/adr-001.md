# ADR 001: Local security lab with an independent enforcement boundary

Accepted: 2026-10-17.

Next.js provides the travel UI; FastAPI owns demo sessions and orchestration. PostgreSQL stores synthetic inventory, reservations, approvals, and audit evidence. Python MCP SDK services expose Streamable HTTP on an internal Docker network. The gateway is a separate service; an agent never receives backend credentials. NGINX routes HTTP but makes no authorization decisions.

The gateway resolves owner, quote, amount, human, workload, and approval from server records. Model text and tool output cannot grant authority. Mutations need atomic, scoped, single-use approval consumption and idempotency. Unknown or unavailable enforcement fails closed.

Only NGINX is published, bound to loopback. MCP services and the database have no host ports or internet egress. The base API has no outbound network, AWS credentials are not mounted, and startup and chat execution reject any non-mock model mode. The inherited Bedrock adapter is dormant and unverified; enabling it is a separate step requiring explicit user cost approval. Production must replace demo identity selection with verified Cognito JWTs and workload authentication. No AWS resource is provisioned by local setup.

The local reference gateway is not a commercial vendor product. The vendor adapter contract remains explicit until a vendor is selected. Unprotected comparisons must use an isolated in-memory simulator without external requests or credentials.
